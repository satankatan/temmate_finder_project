Сначала создай и активируй виртуальное окружение командами\
**python3 -m venv env**\
**source env/bin/activate**

Далее установи зависимости через команду\
**pip install -r requirements.txt**

Запусти команду\
**python3 main.py**

Перейди в finder и дважды щёлкни по **teammate_finder.html**

Если снизу загрузилась статистика значит всё корректно работает и можно потестировать, если не загрузилась смотри ответы сервера - возможно какие-то зависимости не уастановились
